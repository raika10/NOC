# NOC Chess

基本ルールのチェスに、特殊カード(爆弾など)を追加していく実験的なチェスゲーム。

現状は標準ルールのチェス(2人でのローカル対戦)のみを実装済み。今後、以下のような特殊ルールを追加予定:

- 数ターン後に出現する「光るマス」に自分の駒を動かすと爆弾カードを入手
- 入手したカードは両プレイヤーに公開される
- 数ターン以内に設置しないと自爆して敗北
- 爆弾はランダムな形の範囲を、設置後数ターン後に爆破する(キング以外の駒を破壊)

## セットアップ

```bash
npm install
npm run dev
```

`http://localhost:5173` で対局できます。

## スクリプト

- `npm run dev` — 開発サーバー起動
- `npm run build` — 型チェック + 本番ビルド
- `npm run test` — ルールエンジンのユニットテストを実行
- `npm run lint` — 型チェックのみ実行

## 構成

- `src/chess/` — UIに依存しないチェスのルールエンジン(盤面・合法手生成・王手/詰み判定など)
- `src/hooks/useChessGame.ts` — ゲーム状態を扱うReactフック
- `src/components/` — 盤面・対局情報パネル・昇格ダイアログなどのUI
